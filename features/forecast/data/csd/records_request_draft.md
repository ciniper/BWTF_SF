# DRAFT — California Public Records Act request to SFPUC (do not send without review)

**Why SFPUC and not the Regional Board:** everything the Regional Board holds for
these years is already public on CIWQS and has been retrieved. The missing per-event
Westside data (2013–2017) was never filed — under the 2009 permit SFPUC reported only
monthly counts — but SFPUC's own wet-weather summaries cite SCADA/TELOG data tags,
and SFPUC demonstrated (Sep 2023 revised Bayside summaries for Oct 2016–Oct 2017)
that it can produce modern-format tables for historical months. So the records exist
at SFPUC.

**Where to send:** SFPUC public records portal (sf.gov/departments/san-francisco-public-utilities-commission
→ public records / sunshine requests, or via SF's NextRequest portal at
sanfranciscopuc.nextrequest.com). CC option: Region 2 records request
(https://www.waterboards.ca.gov/publications_forms/public_records_request.html) —
only worth it if SFPUC claims it has no responsive records.

Subject: Public Records Act request — per-event combined sewer discharge records, Westside/Oceanside system, 2013–2017

To the Custodian of Records, San Francisco Public Utilities Commission:

Under the California Public Records Act (Gov. Code § 7920.000 et seq.) and the San
Francisco Sunshine Ordinance, I request the following records:

1. Per-event combined sewer discharge (CSD) records for the Westside/Oceanside
   collection system discharge points CSD-001 through CSD-007 (NPDES Permit No.
   CA0037681; Order No. R2-2009-0062, succeeded by Order No. R2-2019-0028), for the
   period January 1, 2013 through December 31, 2017, showing for each discharge
   event: date, discharge point, event start time, event duration, and estimated
   discharge volume.

   Records in the format of the "Oceanside Basin CSD Summary" tables included in the
   Wastewater Enterprise's monthly Self-Monitoring Reports from January 2018 onward
   would fully satisfy this request. If compiled tables do not exist for this period,
   I request the equivalent per-event data as maintained in the Wastewater
   Enterprise's supervisory control/telemetry records (e.g., the overflow level
   sensor and flow records referenced by data tags such as OM1WSS_ANAL and TELOG in
   the monthly wet-weather summaries).

2. (Optional — delete if not wanted) Per-event discharge volumes by discharge point
   for the Bayside system (NPDES Permit No. CA0037664) for January 1, 2013 through
   September 30, 2016, in the format of the revised "FINAL WW Summary" tables the
   SFPUC filed in September 2023 covering October 2016 through October 2017.

Electronic copies (spreadsheet format preferred, PDF acceptable) delivered by email
are requested. If any portion of this request is denied, please cite the specific
exemption relied upon and release any reasonably segregable portions. If the request
would be more efficient to fulfill in another form in which the data exists, I am
glad to confer — my goal is per-event date/outfall/duration/volume records for the
stated period.
