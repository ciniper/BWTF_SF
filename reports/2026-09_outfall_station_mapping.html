Which beaches does each sewer outfall post?

One canonical registry now answers that — shared/outfalls.py — and every consumer reads it: the alerts dashboard's per-station outfall list, the Discharge Ledger map, the forecast label builder's basin table, and the test suite. Before, the mapping was a hand-typed dictionary written from permit prose, with three pseudo-ids (NSB-001, CEN-001, SEB-001) standing in for whole basins, and the station lookup was a keyword match on beach names.

Where the evidence comes from

The Beach_Poo_Bot repository (John Brandon, 2016) archived SFPUC's getCSV feed twice a day from 2016-03-19 to 2017-01-10 — 552 snapshots. The feed names active discharge structures with SFPUC's own labels (SEA CLIFF II, YOSEMITE, …) and, separately, lists which monitoring stations are posted. In the 55 snapshots with an active structure, the stations posted at that moment give a direct structure → station association; the table quotes, for each structure, the share of its active snapshots on which each station was posted. Every Bayside flag-day matched a CIWQS-reported discharge on the same or previous day, so the feed is a trustworthy discharge signal.

Structures that never fired that season (Mile Rock, Sea Cliff #1, the Brick Sewer, Mariposa / 20th / 22nd St, Evans Ave, Fitch St, Howard St) are mapped to the nearest station(s) by distance, checked against the permit's receiving-water text, and tagged permit + geography so the weaker evidence is visible in code.

Headline corrections. Mile Rock (CSD-004) sits at Lands End and had been listed under Ocean Beach and Fort Funston — it's a China Beach outfall. Sea Cliff #2 (CSD-007) posts the three Baker Beach stations and never China Beach. Islais Creek discharges post Islais Creek only, not Crane Cove. Yosemite and Sunnydale discharges post the Candlestick trio together every time. The Marina structures (Baker / Pierce / Laguna St) and the Embarcadero ones (Beach / Sansome / Jackson St) have only ever fired together, so the Crissy-vs-Aquatic split within North Shore is by geography.

What changed in the code

  • shared/outfalls.py — new. 34 Outfall rows (id, CIWQS name, SFPUC feed name, facility, report basin → app basin, receiving water, permit coordinates, stations posted, evidence tag, note) plus the derived views STATION_OUTFALLS, FEED_NAME_TO_OUTFALLS, REPORT_BASIN_TO_APP, BASIN_OUTFALLS and stations_for_feed_name().
  • shared/sfpuc_api.py — CSO_OUTFALLS and BEACH_CSO_OUTFALLS are derived from the registry; _get_cso_outfalls() looks the station up exactly instead of keyword-matching beach names (the keyword match is how "Ocean Beach" swept up Mile Rock).
  • features/discharges/page.py — map locations come from the registry; outfall_locations.csv deleted. Popups now name the beaches SFPUC posts and the structure's feed name.
  • features/forecast/src/collectors/csd_labels.py — asserts its report-basin → app-basin table against the registry at import time.
  • features/forecast/src/collectors/poobot_archive.py — new. Ingests the archive into data/poobot/: feed_status.csv (the evidence above), samples.csv (lab results Dec 2015 – Jan 2017, 3.5 years before DataSF's floor), discharge_onsets.csv (Westside discharge dates CIWQS lacks before 2018).
  • tests/test_outfalls.py — every CIWQS outfall present, every station id valid, feed names resolve to the observed stations, the alerts API and the ledger derive from the registry.
