Sources and how these views were made

The map and chart use live downloads of the selected CW3E feed, with a 15-minute cache per server instance. If a refresh fails, the last successful download from that instance remains explicitly labelled; no bundled snapshot is substituted. Fetching while this page is open does not create a permanent archive. The archive inventory, gauge-API findings and historical comparisons were checked Nov 20, 2026. Coordinates are deduplicated; means use the existing research rectangles. An interval with a missing grid value remains unavailable, and incomplete totals are not treated as zero. Map totals sum observations only.

The archive calendar comes from the local download manifest. Historical bias values come from the repository’s features/forecast/RAIN_SOURCES.md; full API findings are in docs/aqpi-sfpuc-rain-api-investigation.md.
