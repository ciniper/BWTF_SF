By hand

  1. Open the CIWQS eSMR search. Go to the eSMR At-A-Glance report and search the party name San Francisco Public Utilities Commission. It lists every monthly Self-Monitoring Report (SMR) with its period, due date and date received.
  2. Pick both treatment plants for the month you want. Each files its own report:
    • Oceanside plant: permit CA0037681, the Westside outfalls CSD-001–007 (Ocean Beach side).
    • Southeast plant: permit CA0037664, the Bayside outfalls CSD-009–043.
  3. Open the report and download its PDF attachments. The report's detail page lists them; downloads need no account. If a month was amended, use the newest attachment.
  4. Find the discharge table. Bayside: the FINAL WW Summary / CSD Summary pages. Westside: Oceanside Basin CSD Summary (called Westside CSD Summary from May 2026 on).
  5. Copy one row per event: date, outfall, start time, duration and volume in million gallons. A second discharge on the same day is its own row. Keep a volume printed as <0.01 as “less than”.
  6. Trust the daily rows, not the TOTAL row. SFPUC's spreadsheet template sometimes carries a stale monthly total from an earlier month.
  7. Record the month either way. A month with a table and no events is a verified zero, which is different from a month with no report yet. The coverage grid keeps that distinction.

Automated

The same steps as scripts, run on a laptop (not on the website), in features/forecast/src/collectors/csd_ciwqs/:

python list_documents.py --only-new   # 1. list SFPUC's reports on CIWQS
python harvest_index.py               # 2. find each report's attachments
python download_pdfs.py               # 3. download the PDFs
python batch_parse.py                 # 4. read the discharge tables
python aggregate.py                   # 5. clean, check totals, build the CSVs
  • Re-parse one month you already have as a control; its rows must come out identical.
  • Review qa_report.json, append the new rows to features/forecast/data/csd/, copy the manifest, commit and push. Vercel redeploys and the ledger shows the new months.
  • Full notes and the data dictionary: features/forecast/data/csd/NOTES.md.

When

Quarterly, around Mar, Jun, Sep and Dec 15. SFPUC files each month's report 4–6 weeks after the month ends, so the most recent month or two are never there yet.

Known gaps. Westside per-event records before Jan 2018 were never filed (the old permit asked only for monthly counts), and Bayside before Oct 2016 has discharge hours but no volumes. Both exist at SFPUC; see records that aren't public. Don't use the state's data.ca.gov eSMR export to find reports: it skipped SFPUC's Nov–Dec 2025 filings entirely.

By hand

  1. Open the dataset on data.ca.gov: Beach Water Quality Postings and Closures.
  2. Download the resource Beach Posting and Closures – Advisories. It is the whole state in one CSV.
  3. Keep the San Francisco rows: County = San Francisco and CountyCode = SF. Station names such as OCEAN#15_SL are the same ids SFPUC's beach map uses.
  4. Read each row as one sign at one station: up on DateofAdvisory, down on DateOpened, both days counted. AdvisoryType is Posting, Rain or Closure; AdvisoryCause and Source say why.
  5. Sort the cause: sewage when the cause is Combined Sewer Overflow or the source is Combined Sewer Discharge; rain for the 72-hour rain rule; everything else is other (mostly dry-weather bacteria).
  6. Check for bad rows: impossible dates (one row says the year 1014), and filings left open for a year or more, which are kept but not counted as posted days.

How it's recorded

  1. Every minute a scheduled job in our Supabase database reads SFPUC's beach feed, the same data behind the SFPUC beach map.
  2. It compares each station with the minute before. When a station goes from open to posted, to a sewage discharge flag, or back to open, it writes that change and the time to alert_log.
  3. Every half hour it copies the city's lab results from DataSF into a samples table and notes when each result first appeared, which is how the page shows publishing delay.
  4. The page turns those changes into a window per station: sign up, sign down.

To check it yourself

  • Open the SFPUC feed link above in a browser: it shows every station's posted and sewage flags right now.
  • Nothing before Aug 2026 exists in our record. For 2016–17, a volunteer archive of the same feed (Beach Poo Bot) is kept in features/forecast/data/poobot/; for anything else, use Beach Postings above.

Records that aren't public

When a record exists at an agency but isn't published, ask for it under the California Public Records Act.

  1. Ask the agency that holds it. For per-event discharges before 2018 (Westside) and discharge volumes before Oct 2016 (Bayside), that is SFPUC, not the Regional Board, which never received them.
  2. Be specific: permit numbers, outfall ids, date range and the format you want (the modern monthly summary tables are the easiest to ask for, because SFPUC has already produced them for older months once).
  3. Send it through SFPUC's public records request process, asking for electronic copies. Agencies generally have 10 days to respond. If part is refused, ask them to cite the exemption and release the rest.

A ready-to-review draft is in features/forecast/data/csd/records_request_draft.md. It hasn't been sent.
