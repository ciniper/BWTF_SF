By Hand

  1. Open the CIWQS eSMR search. Go to the eSMR At-A-Glance report and search for the party name San Francisco Public Utilities Commission. The report shows all monthly Self-Monitoring Reports (SMR), with the period, due date and date received for each.
  2. Select the two treatment plants for the month that you want. Each plant sends its own report:
    • Oceanside plant: permit CA0037681, the Westside outfalls CSD-001–007 (Ocean Beach side).
    • Southeast plant: permit CA0037664, the Bayside outfalls CSD-009–043.
  3. Open the report and download its PDF attachments. The detail page of the report shows the attachments. You do not need an account to download them. If SFPUC changed a month, use the newest attachment.
  4. Find the discharge table. Bayside: the FINAL WW Summary / CSD Summary pages. Westside: Oceanside Basin CSD Summary (its name is Westside CSD Summary from May 2026). Before 2018, the Westside table is the Wet Weather Discharge Summary in the monthly report. For 2013–2017, it is a scanned page. Before Oct 2016, the Bayside table is the Discharge Summary in the monthly Wet Weather Report. Sometimes the name of this report is WW Report.
  5. Copy one row for each event: date, outfall, start time, duration and volume in million gallons. A second discharge on the same day is a separate row. If the volume is <0.01, record it as “less than”.
  6. Use the daily rows, not the TOTAL row. Sometimes the SFPUC spreadsheet template shows an incorrect monthly total from an earlier month.
  7. Record each month. A month with a table and no events is a verified zero. This is different from a month that has no report yet. The coverage grid shows this difference.

Automated

The same steps as scripts. Run them on a laptop (not on the website). They are in features/forecast/src/collectors/csd_ciwqs/:

python list_documents.py --only-new   # 1. list SFPUC's reports on CIWQS
python harvest_index.py               # 2. find each report's attachments
python download_pdfs.py               # 3. download the PDFs
python batch_parse.py                 # 4. read the discharge tables
python aggregate.py                   # 5. clean, check totals, build the CSVs
  • As a control, parse one month again that you already have. Its rows must be the same.
  • Examine qa_report.json. Add the new rows to features/forecast/data/csd/. Copy the manifest. Commit and push. Vercel deploys the site again, and the ledger shows the new months.
  • For all the notes and the data dictionary, refer to features/forecast/data/csd/NOTES.md.

When

Each quarter, on approximately Mar, Jun, Sep and Dec 15. SFPUC sends the report for each month 4–6 weeks after the month ends. Thus, the most recent one or two months are never available yet.

Known gaps. No data is online before Mar 2011. Before Jan 2018, the Westside reported daily totals for each outfall, with no start times. Before Oct 2016, the Bayside reported hours for each group of outfalls, with no volumes. All the differences are on How discharge reporting changed. SFPUC possibly has the missing data (refer to records that are not public). Do not use the data.ca.gov eSMR export from the state to find reports. It did not include the SFPUC reports for Nov–Dec 2025.

By Hand

  1. Open the dataset on data.ca.gov: Beach Water Quality Postings and Closures.
  2. Download the resource Beach Posting and Closures – Advisories. It is one CSV for the full state.
  3. Keep the San Francisco rows: County = San Francisco and CountyCode = SF. Station names, for example OCEAN#15_SL, are the same IDs that the SFPUC beach map uses.
  4. Each row is one sign at one station: it goes up on DateofAdvisory and comes down on DateOpened. Count the two days. AdvisoryType is Posting, Rain or Closure. AdvisoryCause and Source give the reason.
  5. Sort the cause: sewage, when the cause is Combined Sewer Overflow or the source is Combined Sewer Discharge. Rain, for the 72-hour rain rule. All other causes are "other" (usually dry-weather bacteria).
  6. Look for bad rows: dates that are not possible (one row gives the year 1014), and advisories that stay open for one year or more. Keep these advisories, but do not count them as posted days.

When

Each quarter, with the discharge refresh. San Francisco sends its postings to the State some months late. Thus, the newest months are always missing. The Online Postings Timeline below fills that gap from Aug 2026.

How We Record It

  1. Each minute, a scheduled job in our Supabase database reads the SFPUC beach feed. The SFPUC beach map uses the same data.
  2. It compares each station with the minute before. A station can change from open to posted, to a sewage discharge flag, or back to open. When this occurs, the job writes the change and the time to alert_log.
  3. Each 30 minutes, it copies the city lab results from DataSF into a samples table. It records when each result first came online. The page uses this to show the publishing delay.
  4. The page changes these records into a window for each station: sign up, sign down.

To Examine It Yourself

  • Open the SFPUC feed link above in a browser. It shows the posted and sewage flags for all stations now.
  • Our record has no data before Aug 2026. For 2016–17, a volunteer archive of the same feed (Beach Poo Bot) is in features/forecast/data/poobot/. For other dates, use Beach Postings above.

Records That Are Not Public

If an agency has a record but does not publish it, ask for it under the California Public Records Act.

  1. Ask the agency that has the record. For discharge start times before 2018 (Westside), discharge volumes before Oct 2016 (Bayside), and all data before Mar 2011, this agency is SFPUC.
  2. Give specific data: permit numbers, outfall IDs, date range, and the format that you want. (It is easiest to ask for the modern monthly summary tables, because SFPUC already made them for older months one time.)
  3. Send the request through the San Francisco records portal (department “PUC - Public Utilities Commission”). Ask for electronic copies. For reports from before March 2011, also ask the Regional Board at RB2-PRA-Request@Waterboards.ca.gov. Usually, agencies must reply in 10 days. If they refuse part of the request, ask them to give the exemption and send the remaining records.

A draft that is ready for review is in features/forecast/data/csd/records_request_draft.md. We did not send it.
