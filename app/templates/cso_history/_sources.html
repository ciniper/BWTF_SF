Sources & API links · How to read the dates
  • SFPUC map status API — getBeaches: stations, sample_date, posting and discharge flags. Checked about once a minute; also supplies the daily gray/green history.
  • SFPUC early lab results API — getCSV: lab indicator results by station and collection date, which can appear before DataSF. Checked about every two minutes.
  • DataSF lab results API — JSON: published water-quality measurements, mirrored about every half hour. Dataset documentation.
  • This site's timeline API — saved observations: posting events and sample arrival history used by the main timeline. Daily colors API — saved station-day summaries (defaults to 14 days; accepts start and end dates).
  • SFPUC public beach map: the public-facing map, rather than a raw API response.

Collection date: sample_date is when water was collected. Publication time: when the source made a result public. First observed: when our watcher first saw it; periodic checks do not establish the exact publication time. “Seen by” means it was already present when recording began.

A posting change alone does not establish a new sample. Flags, sample dates and results can update independently. Source links show current responses; these timelines use saved observations.
