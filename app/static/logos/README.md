# Logos on /architecture

Each company's or agency's own mark, used only to name the service in the
infrastructure diagram (`app/templates/about/architecture.html`). Fetched 2026-09-29.

| File | Source |
|---|---|
| `supabase.svg`, `vercel.svg`, `github.svg`, `brevo.svg` | Simple Icons (CC0), `cdn.jsdelivr.net/npm/simple-icons/icons/<name>.svg`, filled with each brand's colour |
| `sfpuc.png` | sfpuc.gov favicon (`/themes/custom/sfwater/img/favicon-128.png`) |
| `noaa.svg` | noaa.gov header logo (`noaa_logo_mobile.svg`), cropped to the emblem |
| `healthchecks.svg` | healthchecks.io favicon (`/static/img/favicon.svg`) |
| `sf-city-seal.png` | City and County of San Francisco seal from sf.gov (`/_next/static/media/CCSF-seal-vector.f4f3942a.svg`, 2.3 MB), rasterized to 128 px; DataSF is the City's open-data program |
| `water-boards.png` | waterboards.ca.gov header banner (`/images/banner/web_menu_graphic_sb.png`), cropped to the wave mark; CIWQS and BeachWatch are both State Water Board systems |

The Surfrider BWTF mark is the repo's own `app/static/brand/bwtf_144x144.png`.
Only Subscribers and Visitors keep icons (people, not services).
